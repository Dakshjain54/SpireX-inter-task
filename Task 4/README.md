# 🔐 Login / Signup Form UI

A modern, responsive, and user-friendly **Login/Signup Form UI** built using **HTML, CSS, and JavaScript**. This project allows users to switch between Login and Registration forms with smooth animations and client-side form validation.

---

## 📌 Project Overview

The Login/Signup Form UI is designed to provide a clean and interactive authentication interface for web applications. It includes separate Login and Signup forms, real-time input validation, password visibility toggle, and responsive design for all screen sizes.

## 🚀 JavaScript Functionality

- Switch between Login and Signup forms.
- Validate user inputs before submission.
- Display error messages for invalid fields.
- Highlight valid and invalid inputs.
- Show/Hide password functionality.
- Password strength indicator.
- Display success message after successful validation.
- Reset form after successful submission.
