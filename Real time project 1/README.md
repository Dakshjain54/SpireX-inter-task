# ♻️ Smart Waste Management Dashboard

A modern, responsive, and interactive **Smart Waste Management Dashboard** built using **HTML, CSS, and JavaScript**. The dashboard provides a real-time overview of waste bin levels, recycling statistics, waste collection status, and smart city analytics through an attractive and user-friendly interface.

---

# 📌 Project Overview

The **Smart Waste Management Dashboard** is designed to simulate a real-world IoT-based waste monitoring system. It helps monitor smart waste bins, track collection status, analyze recycling performance, and visualize waste management data through animated charts and interactive dashboard components.

The dashboard features a premium glassmorphism design, responsive layout, smooth animations, and simulated real-time updates without using any backend.
