# 📱 Responsive Navbar

A simple, clean, and fully responsive **Navigation Bar** built using **HTML, CSS, and JavaScript**. The navbar automatically adapts to different screen sizes, providing a smooth and user-friendly navigation experience on desktops, tablets, and mobile devices.

---

## 📌 Project Overview

This project demonstrates how to build a responsive navigation bar without using any CSS frameworks or libraries. It features a modern design, a mobile-friendly hamburger menu, and smooth animations to enhance the user experience.

## 🚀 Features Explained

### 🖥️ Desktop View
- Logo displayed on the left.
- Navigation links centered.
- Login button on the right.

### 📱 Mobile View
- Navigation links are hidden by default.
- A hamburger menu icon is displayed.
- Clicking the hamburger icon opens and closes the navigation menu.
- Navigation links are displayed vertically for better usability.
