# Online Examination System (Student Mini Project)

A simple, clean, and functional **Online Examination System** mini-project built using standard HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Features

- **Start Screen**: Student name input with empty field validation.
- **Exam Screen**: 10 MCQs with dynamic progress bar and 5-minute countdown timer.
- **Answer Selection & Navigation**: Choice selection persists while navigating back and forth (`Previous` / `Next`).
- **Standard Submit**: Native JavaScript submission confirmation prompt (`confirm()`).
- **Result Summary**: Clear display of Score (`8 / 10`), Percentage (`80%`), Correct, and Wrong answers.
- **Try Again**: Instant reset function to restart the exam.
