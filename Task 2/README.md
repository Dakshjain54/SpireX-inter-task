# 📄 Simple Resume / CV Webpage

A modern, colorful, responsive, and professional **Resume/CV Website** built using **HTML, CSS, and JavaScript**. This project transforms a traditional resume into an interactive single-page portfolio with smooth animations and an attractive user interface.

---

## 📌 Project Overview

This Resume/CV webpage presents personal, educational, and professional information in a clean and visually appealing format. The website is fully responsive, easy to navigate, and designed with a premium yet simple user experience.

---

## ✨ Features

- 🎨 Modern & Colorful UI
- 📱 Fully Responsive Design
- 🌟 Attractive Hero Section
- 👤 About Me Section
- 🎓 Education Timeline
- 💻 Skills with Animated Progress Bars
- 🚀 Projects Showcase
- 📜 Training & Certifications
- 📞 Contact Information
- 🌙 Dark / Light Mode Toggle
- 📄 Download Resume Button
- 🔝 Scroll-to-Top Button
- ✨ Smooth Hover Effects
- 📌 Sticky Navigation Bar
- 📅 Dynamic Current Year
- ⚡ Lightweight & Fast Loading
