# Shopping Mart — Mini Project

A simple online shopping website created using standard **HTML5**, **CSS3**, and **Vanilla JavaScript**.

---

## 🎯 Features

- **Product Showcase**: Displays 8 everyday products with title, image, price in ₹, and an "Add to Cart" button.
- **Product Search**: Live search bar that filters products instantly as you type.
- **Shopping Cart**:
  - Add products to cart.
  - Increase (`+`) or decrease (`-`) product quantities.
  - Remove items from cart.
  - Live subtotal calculation.
  - Badge counter in the header showing total items in cart.
- **Local Storage Persistence**: Cart state remains saved even after page refresh.
- **Order Placement**: "Place Order" button that clears the cart and shows an order confirmation modal.
- **Responsive Layout**: Works seamlessly across Desktop, Tablet, and Mobile screens.
