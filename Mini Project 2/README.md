# 🛒 Shopping Mart

**Shopping Mart** is a simple and responsive online shopping website built using **HTML5, CSS3, and Vanilla JavaScript**.

The project allows users to browse products, search for items, add products to a cart, manage quantities, and place a simple order.

---

## ✨ Features

* 🛍️ Browse products
* 🔍 Search products
* 🛒 Add products to cart
* ➕ Increase product quantity
* ➖ Decrease product quantity
* 🗑️ Remove products from cart
* 💰 Automatic total price calculation
* 🔢 Cart item counter
* 💾 Cart saved using LocalStorage
* 📦 Simple order placement
* 📱 Responsive design
* ✨ Basic hover animations

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, layout, and responsive design
* **Vanilla JavaScript** — Product display, cart functionality, search, and calculations
* **LocalStorage** — Saving cart data

No external frameworks or libraries are used.

## 🎨 Design

The project uses a simple and clean e-commerce design with:

* Light background
* Simple navigation bar
* Product cards
* Clean buttons
* Basic shadows
* Responsive product grid
* Small hover effects

The design intentionally avoids unnecessary animations and complicated UI to keep the project simple and easy to understand.

---

## 📱 Responsive Design

The website is designed for:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

The product grid automatically adjusts according to the screen size.

---

## 🎯 Project Objective

The objective of this mini project was to create a **simple and functional shopping website** while understanding how frontend technologies can be combined to create a basic e-commerce experience.

The project focuses on functionality, clean design, and simple implementation rather than unnecessary complexity.
