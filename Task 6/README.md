# 🧮 BMI Calculator

A simple, attractive, and responsive **BMI Calculator** built using **HTML, CSS, and Vanilla JavaScript**.

The application calculates Body Mass Index instantly based on the user's height and weight and displays the corresponding BMI category.

---

## ✨ Features

* 🧮 Instant BMI calculation
* 📏 Height input in centimeters
* ⚖️ Weight input in kilograms
* 📊 Displays BMI value
* 🏷️ Shows BMI category
* ⚠️ Input validation
* ✨ Smooth UI animations
* 📱 Fully responsive design
* 🎨 Modern premium glassmorphism UI

## 🧠 BMI Formula

The calculator uses the standard BMI formula:

```text
BMI = Weight (kg) / Height (m)²
```

Example:

```text
Height = 175 cm
Weight = 70 kg

BMI = 70 / (1.75 × 1.75)
BMI = 22.9
```

## 📊 BMI Categories

| BMI Range   | Category      |
| ----------- | ------------- |
| Below 18.5  | Underweight   |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9   | Overweight    |
| 30+         | Obese         |
