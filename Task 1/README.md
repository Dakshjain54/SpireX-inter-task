# 🎨 Personal Portfolio Card

A modern and responsive **Personal Portfolio Card** built using **HTML, CSS, and JavaScript**. This project showcases a premium glassmorphism design with smooth animations, interactive effects, and a clean user interface.

---

## 📌 Project Overview

The Personal Portfolio Card is designed to present a developer's profile in a visually appealing and interactive way. It includes a profile image, personal information, social media links, action buttons, and modern UI animations while maintaining a lightweight structure.

---

## 🚀 Features

* ✨ Modern Glassmorphism UI
* 🌙 Dark Theme Design
* 📱 Fully Responsive Layout
* 🎭 Smooth CSS Animations
* 🖱️ JavaScript Mouse Tilt Effect
* 💡 Cursor Glow Effect
* 🖼️ Animated Profile Image
* 🎯 Typing Animation
* 🔗 Social Media Icons
* 📄 Download Resume Button
* 📬 Contact Me Button
* 🎨 Animated Gradient Background
* ⚡ Lightweight & Fast Loading
* ♿ Semantic HTML Structure

---
