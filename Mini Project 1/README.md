# 🎮 Rock Paper Scissors Game

A modern, colorful, and interactive **Rock Paper Scissors Game** built using **HTML, CSS, and JavaScript**. The game features smooth animations, dynamic gameplay, score tracking, sound effects, and a premium user interface. Players compete against the computer, and the first to score **5 points** wins the match.

---

## 📌 Project Overview

This project is a browser-based implementation of the classic **Rock Paper Scissors** game. It combines responsive design, interactive animations, and JavaScript logic to provide an engaging gaming experience. The interface is designed to fit on a single screen without scrolling and works seamlessly across desktop, tablet, and mobile devices.

## 🎯 Game Rules

- Choose **Rock**, **Paper**, or **Scissors**.
- The computer makes a random choice.
- The winner of each round is decided instantly.
- Scores are updated automatically.
- The first player to reach **5 points** wins the game.
- A winner popup, trophy animation, and confetti celebration appear after the match.
- Click **Play Again** to restart the game.
