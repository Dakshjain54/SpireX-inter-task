# ⌨️ Typing Speed Test

A modern and interactive **Typing Speed Test** built using **HTML5, CSS3, and Vanilla JavaScript**.

The application allows users to test their typing speed and accuracy by typing a given paragraph. It calculates **WPM, accuracy, time taken, and typing progress** in real time.

---

## ✨ Features

* ⌨️ Real-time typing test
* 🚀 WPM (Words Per Minute) calculation
* 🎯 Accuracy percentage
* ⏱️ Automatic timer
* 📊 Live typing statistics
* 📈 Typing progress bar
* 🔴 Incorrect character highlighting
* 🟢 Correct character tracking
* 📝 Multiple typing paragraphs
* 🔄 Try Again functionality
* 🎲 New Text option
* 🏆 Final performance message
* 📱 Responsive design
* ✨ Modern animations

## 🎨 Design

The application uses a modern dark interface with:

* Clean typography
* Rounded cards
* Subtle gradients
* Soft shadows
* Interactive statistics
* Progress indicator
* Smooth transitions
* Responsive layout

* 💻 Desktop

* 📱 Tablet
