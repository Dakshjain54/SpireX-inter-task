# 🎨 ColorCraft — Color Palette Generator

A modern and interactive **Color Palette Generator** built using **HTML, CSS, and Vanilla JavaScript**.

ColorCraft allows users to generate beautiful color palettes, lock individual colors, copy HEX values, save favorite palettes, and export palettes for later use.

---

## 🚀 Live Features

* 🎨 Dynamic 5-color palette generation
* 🔒 Lock / Unlock individual colors
* 📋 Copy individual HEX colors
* 📋 Copy complete palette
* 🎛️ Multiple palette generation styles
* ❤️ Save favorite palettes
* 💾 Store saved palettes using LocalStorage
* 🗑️ Delete saved palettes
* 📥 Export palette as a `.txt` file
* ⌨️ Generate palette using the **Spacebar**
* 🔔 Copy confirmation toast notification
* ✨ Smooth animations and transitions
* 📱 Fully responsive design

## 🎯 Palette Styles

ColorCraft supports different color-generation styles:

* **Random** — Generates completely new colors
* **Monochromatic** — Uses different shades of a similar hue
* **Analogous** — Generates colors close to each other on the color wheel
* **Complementary** — Generates contrasting colors
* **Triadic** — Generates colors based on a three-color combination
